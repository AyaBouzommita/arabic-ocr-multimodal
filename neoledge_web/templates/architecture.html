System Architecture

A multi-layered, hallucination-resistant approach to extracting and reconstructing Arabic and bilingual documents with extreme precision.

🎯

1. YOLOv11s Layout Parser

The core of our extraction pipeline. Our custom-trained YOLOv11s model perfectly isolates text blocks, tables, and lists before any OCR happens, entirely eliminating hallucination risks.

🔀

2. Dual OCR Pipelines

We found that PaddleOCR handled languages independently but struggled with mixing. Therefore, we developed a dual pipeline: EasyOCR handles AR/EN extraction, while PaddleOCR is optimized for FR/EN text.

🧠

3. AraBERT & RoBERTa

Context-aware Masked Language Modeling engines evaluate contextual probability for Arabic and bilingual words to catch nuanced OCR errors that normal tools miss.

📖

4. Strict Dictionary Validation

Following the MLM inference, rigorous dictionary benchmarking validates terms to ensure that zero hallucinations or non-existent words pass through the final spellchecker.

☁️

5. Gemini Reconstructor

Gemini Cloud AI acts purely as a structural organizer. It processes the perfectly extracted string arrays and injects clean Markdown formatting for beautiful, structured presentation.

🚀

6. Colab VLM Offloading

For ultra-dense or highly complex documents, the workload is instantly offloaded via an API to a Google Colab T4 GPU running a quantized Qwen2-VL heavy model.
